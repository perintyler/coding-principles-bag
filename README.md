# coding-principles

Four principles describing how code is expected to read: **naming**,
**commenting**, **documenting**, and **testing**. They ship as on-demand
instructions — `search_instructions` lists them, `get_instructions <name>`
returns one in full.

This bag is prose only. It has no tools, no services, and no scripts; the
`coding` bag composes it, and that bag's `IC` trait names these instructions so
an identity granting `IC` sees a one-line pointer to each before it writes any
code.

These lived in the barry monorepo as a `principles/` directory wired into
`AGENTS.md`. That delivered them to sessions started in one working directory
and nowhere else. Here they travel with the bag.
